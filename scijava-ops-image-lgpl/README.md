# SciJava Ops Image LGPL

Image processing ops for [SciJava Ops](https://github.com/scijava/scijava)
translated from LGPL-licensed ImageJ and Fiji plugins, such as
[MorphoLibJ](https://github.com/ijpb/MorphoLibJ).

[SciJava Ops Image](../scijava-ops-image) is BSD-2 licensed, so algorithms
that are only available as LGPL code, and that cannot practically be
reimplemented from their published descriptions, live here instead. Keeping
them apart from [SciJava Ops Image GPL](../scijava-ops-image-gpl) lets
downstream projects depend on them without GPL obligations. Each op credits
the original authors, project and license in its javadoc.
